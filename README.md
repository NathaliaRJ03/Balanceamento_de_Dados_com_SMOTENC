# ⚖️ Balanceamento de Dados com SMOTENC

Este projeto demonstra a utilização do **SMOTENC** para realizar o balanceamento de classes em um conjunto de dados que possui **variáveis categóricas**, utilizando **Python**, **Pandas**, **Scikit-learn** e **Imbalanced-learn**.

## 🚀 Tecnologias

* 🐍 Python
* 🐼 Pandas
* 🤖 Scikit-learn
* ⚖️ Imbalanced-learn

## ⚙️ Funcionalidades

* 📂 Leitura do conjunto de dados
* 🏷️ Codificação de variáveis categóricas com `LabelEncoder`
* 📊 Verificação do desbalanceamento das classes
* ⚖️ Aplicação do algoritmo `SMOTENC`
* 📈 Geração de um conjunto de dados balanceado

## ▶️ Como executar

Instale as dependências:

```bash
pip install pandas numpy scikit-learn imbalanced-learn
```

Execute o script:

```bash
python smotenc.py
```
